# 🤖 Hermes Agent

هوش مصنوعی پاسخگو در تلگرام و بلاه.

## متغیرهای محیطی

| Variable | Description |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام |
| `TELEGRAM_ALLOWED_USERS` | شناسه‌های مجاز تلگرام |
| `BALE_BOT_TOKEN` | توکن ربات بلاه |
| `BALE_ALLOWED_USERS` | شناسه‌های مجاز بلاه |
| `OPENAI_API_KEY` | کلید OpenAI |
| `ANTHROPIC_API_KEY` | کلید Anthropic |
